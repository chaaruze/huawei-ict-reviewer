# Network Track Sprint

A free, self-contained study site for the **Huawei ICT Competition — Network Track** preliminary
(Datacom, Security, WLAN, DCN): plain-language micro-lessons with diagrams, spaced-repetition
flashcards, a timed 60-question mock exam, drills (subnetting, ports, OSI, IPv6…) and eNSP labs.

Open the site: see the GitHub Pages link in this repository's About section.

Progress is saved in your own browser (localStorage) — nothing is uploaded.
Not affiliated with Huawei. Page references point to the open-access textbook
*Data Communications and Network Technologies* (Huawei / Springer, 2023).
